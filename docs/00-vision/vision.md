# Vision

AMS Task 2 — небольшой воспроизводимый сервис управляемой автономности.

Система принимает цель пользователя, строит ограниченный детерминированный план, проверяет каждый
инструмент через policy и gateway, выполняет чтение, а запись в режиме `confirm` отдаёт пользователю
на одноразовое подтверждение.

Ценность прототипа — показать контролируемое выполнение, объяснимый план, безопасный отказ и audit,
а не автономность без ограничений.
