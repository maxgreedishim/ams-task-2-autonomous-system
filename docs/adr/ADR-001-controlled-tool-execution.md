# ADR-001: Controlled tool execution

## Decision

Planner создаёт только структурированный план. Policy валидирует режим, tool, args, workspace и
limits. Gateway является единственным исполнителем tools.

## Why

Так запись нельзя выполнить напрямую из planner или из недоверенного tool output. Подтверждение
хранится как одноразовый переход состояния task.

## Consequences

- архитектура детерминирована и тестируема;
- реальный adapter можно подключить на месте mock gateway;
- полноценная аутентификация остаётся отдельным следующим шагом.
