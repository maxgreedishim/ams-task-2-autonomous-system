# Glossary

| Термин | Значение |
|---|---|
| Task | Автономная задача с целью, режимом, лимитами и состоянием. |
| Workspace | Изолированное пространство данных; в demo используется `demo-a`. |
| Planner | Детерминированный построитель структурированного плана. |
| Policy | Allowlist-проверка инструмента, аргументов, режима, workspace и лимитов. |
| Gateway | Единственная точка вызова mock-инструментов. |
| Tool | Типизированная операция `list_records`, `get_record` или `create_followup`. |
| Confirmation | Одноразовое разрешение ожидающей записи. |
| Audit event | Упорядоченная запись перехода, policy-check или вызова gateway. |
